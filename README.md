## 📖 Giới Thiệu

FLARE AI là Discord Bot được tích hợp OpenAI, chuyên hỗ trợ lập trình viên:

- 💬 **Chat AI** - Trò chuyện thông minh với AI
- 💻 **Viết Code** - Tạo code theo yêu cầu
- 🐛 **Debug** - Tìm và sửa lỗi code
- 📚 **Giải Thích** - Explain code và concepts
- 🔍 **Review** - Đánh giá chất lượng code

## 🚀 Cài Đặt Nhanh

```bash
# 1. Clone repository
git clone https://github.com/your-username/flare-ai-discord.git
cd flare-ai-discord

# 2. Cài đặt thư viện
pip install -r requirements.txt

# 3. Tạo file .env từ mẫu
cp .env.example .env

# 4. Điền token vào file .env
# DISCORD_TOKEN=your_discord_token
# OPENAI_API_KEY=your_openai_key

# 5. Chạy bot
python run.py
